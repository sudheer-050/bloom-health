# Bloom Daily design context

Bloom is a local personal wellness journal built with semantic HTML, CSS, JavaScript and a Python standard-library server.

The redesign uses muted sage accents, a charcoal navigation rail, warm white surfaces, rounded cards and local Segoe UI/Bahnschrift typography. `dist/design.css` owns the visual system; `dist/icons.js` supplies local SVG icons. Mobile uses a persistent seven-item bottom navigation.

Preserve guest access below Sign in, the transparent fitness image and fixed-height login, existing saved journals, encrypted accounts and portable backups. Online photo AI remains optional and explicitly requested. Manual nutrient estimates stay local. Unknown micronutrients must remain visibly unknown.

See [REDESIGN.md](REDESIGN.md) for retrieved 21st catalog references and verification.

The public homepage is a separate product landing page with an editorial hero, transparent lifestyle image, labeled example journal, real feature sections, local-data explanation and create/sign-in/guest actions. `landing.css` and `landing.js` own this surface. The homepage scrolls; login and signup remain fixed-height.
